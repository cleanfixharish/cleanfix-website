# CleanFixHarish Private System Backup

This private repository is the safe off-device backup for the CleanFixHarish operating system,
knowledge base, website source, manager dashboard, approved visual assets, and project documents.

## Canonical sources

- Website code: `cleanfixharish/cleanfix-website`
- Private system backup: `cleanfixharish/cleanfixharish-system-backup`
- Local master copy: `C:\Users\Aviel\Desktop\Aviel's GPT workspace Files and Dashboard\all System files`

## Safety rules

- Keep this repository private.
- Never commit passwords, access tokens, API keys, OAuth secrets, `.env` files, private keys, or customer exports.
- GitHub remains the canonical source for website code; this repository is a safety snapshot and business knowledge backup.
- Update this backup after material changes to project documents, system instructions, dashboard source, or approved visuals.
- Review the staged file list and run a secret scan before every push.

## Excluded from GitHub

Dependency folders, virtual environments, caches, logs, build output, Git internals, secrets, and duplicate ZIP exports are intentionally excluded. They remain unnecessary for restoring the project because they can be recreated or already exist in the local master copy.
